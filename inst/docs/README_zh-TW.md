# NSCA：充分必要條件分析

本套件於 R 中實作充分必要條件分析（Necessary and Sufficient Condition Analysis, NSCA）。

## 方法簡介

若缺少某一條件時結果不會出現，該條件即為結果的**必要條件**；若該條件的存在即可
保證結果出現，則為**充分條件**。當一個條件同時為必要與充分條件時，它在每一個結果
水準上界定一條分界線：低於此線，該水準無法達成；高於此線，則可保證達成。

此一主張的兩個部分各自對資料隱含明確的預測。若以條件 X 對結果 Y 繪製散佈圖，
必要性預測某一角落為空白，充分性則預測其對角的角落為空白。以「高 X 是高 Y 的
充分必要條件」為例，資料中不應出現低 X 而高 Y 的個案（左上），也不應出現高 X
而低 Y 的個案（右下）。

NSCA 在相同的資料、相同的範圍與相同的邊界估計方法下估計這兩個空白角落，分別衡量
其大小，並分別與 X、Y 的隨機配對比較以進行檢定，最後再綜合評估兩者。兩條邊界之間
的帶狀區域稱為**可容許區域**（admissible region），即兩項主張皆未排除的組合。此區域
越窄，兩者的關係越接近嚴格的充分必要關係。

| 方向 | 主張 | 必要性空白角落 | 充分性空白角落 |
|:---:|---|---|---|
| `HH` | 高 X 是高 Y 的充分必要條件 | 左上 | 右下 |
| `LH` | 低 X 是高 Y 的充分必要條件 | 右上 | 左下 |
| `HL` | 高 X 是低 Y 的充分必要條件 | 左下 | 右上 |
| `LL` | 低 X 是低 Y 的充分必要條件 | 右下 | 左上 |

## 用途

- **檢定「既為必要、亦為充分」的主張。** 許多理論將某一條件視為前提，且一旦滿足
  即可帶來結果。NSCA 在同一份資料上檢定這兩個成分，僅於兩者皆獲支持時，才判定
  聯合主張獲得支持。
- **確定分界線的位置。** 雙門檻表針對每一個結果水準，列出該結果所需的 X 水準、
  足以保證該結果的 X 水準，以及介於兩者之間、結果「可能達成但無法保證」的區間。
- **評估關係接近充分必要的程度。** 聯合表列出兩個成分各自的效果量，以及三種綜合
  兩者的摘要指標。
- **補充迴歸分析。** `nsca_compare()` 將迴歸斜率與兩個效果量並列，使研究得以說明
  資料所呈現的是平均效果、條件效果，或兩者兼具。
- **研究規劃。** `nsca_power()` 估計同時偵測兩個成分所需的觀測值數量。

## 安裝

```r
install.packages("NSCA")
```

安裝時會一併安裝用於估計必要性的 NCA 套件，以及用於估計充分性的 SCAtools 套件。

## 使用方式

```r
library(NSCA)

# 落在帶狀區域內的模擬資料，兩個角落都是空的
set.seed(1)
dat <- nsca_random(n = 100, d_nec = 0.3, d_suf = 0.3)

# 1. 配適「高 X 是高 Y 的充分必要條件」
fit <- nsca_analysis(dat, x = "X", y = "Y", direction = "HH",
                     test.rep = 1000)
fit                     # 三層結果，並列出結果所依據的每一項設定

# 2. 讀取結果
nsca_results(fit)       # 必要性、充分性與聯合三張表
nsca_table(fit)         # 聯合表與聯合支持判定
nsca_thresholds(fit)    # 需要的水準、保證的水準與兩者之間的區間
nsca_plot(fit)          # 兩條邊界與可容許區域

# 3. 與迴歸並列
nsca_compare(fit)
```

`nsca()` 可一次完成相同的分析（含置換檢定）並繪製圖形；`nsca_output()` 則輸出撰寫
報告通常所需的表格與圖形：

```r
nsca(dat, x = "X", y = "Y", direction = "HH")
nsca_output(fit, thresholds = TRUE, tests = TRUE)
```

### 結果檢核

| 函數 | 呈現內容 |
|---|---|
| `nsca_test_plot()` | 兩個成分的置換分配與觀測效果量 |
| `nsca_shared_plot()` | 共用置換序列下兩側各自、兩側最小值與兩側加總的分配 |
| `nsca_scope()` | 兩個效果量所除以的範圍（scope） |
| `nsca_scope_sensitivity()` | 兩個成分與聯合摘要隨範圍改變而產生的變化 |
| `nsca_resample()` | 上述數值在子樣本間的變異 |
| `nsca_outliers()` | 決定各條邊界位置的觀測值 |
| `nsca_locationshift()` | 各條邊界屬於整體水準平移或門檻 |
| `nsca_magnitude()` | 成分效果量的慣用大小等級 |

## 結果解讀

**兩個成分。** `d_nec` 與 `d_suf` 為空白面積占範圍的比例，介於 0 與 1 之間。並列的
`d_nec_null` 與 `d_suf_null` 為同一份資料在隨機配對下所得之值；`d_nec_critical`
與 `d_suf_critical` 為隨機配對下僅有 5% 機率會超過的值，亦即單一檢定下兩個成分
各自的臨界值。分析多個條件時，`nsca_table(fit, p.adjust = "holm")` 會對 p 值進行
多重檢定校正；臨界值則仍為單一檢定的參考線。

**三種聯合摘要。**

| 欄位 | 所回答的問題 |
|---|---|
| `weakest_effect` | 兩項主張中較弱者的強度 |
| `balanced_joint_effect` | 兩者合併的強度，兩者越平衡則數值越高 |
| `joint_empty_space_coverage` | 兩項主張合併排除了多少比例的範圍 |

`nsca_joint()` 可計算介於上述摘要之間的整個指標族，涵蓋從兩個成分之間完全不互補
到完全互補的情形。

**p 值。** 各 p 值回答不同的問題；`joint_support` 依據第一個 p 值：

| 欄位 | 所回答的問題 |
|---|---|
| `p_nsca_iut` | 兩個角落是否各自都比隨機配對下更空？`max(p_nec, p_suf)` |
| `p_weakest_perm` | 較小的空白面積是否大於隨機配對所產生者？ |
| `p_sum_perm` | 兩個角落合併後是否比隨機配對下更空？ |

`p_nsca_iut` 僅在兩個成分的檢定皆拒絕虛無假設時才達顯著，因此合併兩者無須另行
校正。另外兩個 p 值需要設定 `shared.test.rep`，使兩側採用同一組置換；僅一個角落
明顯空白，即可能使 `p_sum_perm` 偏小。建議在檢視結果之前，先選定能回答研究問題
的 p 值。

**聯合支持。** 當兩個成分皆達顯著、兩者皆達到以 `relevance =` 設定的實務門檻
（若有設定），且兩條邊界的幾何關係可接受時，`joint_support` 為 `TRUE`。並列的
個別旗標顯示每一列符合哪些條件。

**雙門檻。** 以高 X 方向為例，每一個結果水準將 X 軸分為三段：

| X | 該結果水準 |
|---|---|
| 低於 `necessity_threshold` | 無法達成 |
| 介於兩個門檻之間 | 可能達成，但無法保證 |
| 高於 `sufficiency_threshold` | 可保證達成 |

低 X 方向的不等號則相反。`necessity_sufficiency_interval` 為中間區段的寬度；當
寬度為 0 時，`threshold_status` 會標示為 `exact correspondence`。

## 建議做法

- **方向的選擇。** 建議依據理論決定方向，再以圖形檢視資料。每一個方向在兩側各
  預測一個空白角落，其前提為變數間的關係具單調性。
- **報告範圍（scope）。** 每一個效果量皆為面積除以範圍，因此宜說明所採用的是觀測
  範圍或理論範圍，以及採用的理由。`nsca_scope()` 與輸出中的 `Settings` 區塊均記錄
  此項設定。
- **報告邊界估計方法與置換次數。** 兩側使用同一種方法；指定多種方法時，每種方法
  各占一列。置換次數一般採用 1000 次以上。
- **事先設定實務門檻。** 若結論取決於效果量是否達到某一最低值，可於分析前以
  `relevance =` 指定。
- **依研究設計校準聯合摘要。** 各成分效果量有慣用的大小等級
  （`nsca_magnitude()`）；聯合摘要則可藉由 `nsca_power()` 與 `nsca_resample()`
  了解該研究設計可能產生的數值。

可透過 `reference = "ols"` 或 `"qr"` 加入一條最小平方法或中位數迴歸線作為對照，
並由 `nsca_reference()` 報告；該線不屬於任何一個成分。

## 延伸閱讀

- `?NSCA`：方法說明與參考文獻。
- `citation("NSCA")`：引用格式。

  完整的範例。
